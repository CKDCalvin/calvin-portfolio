## About

This portfolio was built to highlight my experience as a software developer and frontend engineer. It features selected projects, technical skills, and links to my professional profiles.

### `Features`

* Responsive design for desktop and mobile devices
* Professional project showcase
* Skills section highlighting development technologies
* Direct links to Github, LinkedIn, Email
* Modern React-based single-page application

## Installation

### Run Locally

```bash
git clone https://github.com/CKDCalvin/calvin-portfolio.git

cd calvin-portfolio 

npm install
 
npm start
```

The application is available at: \i
[http://localhost:3000](http://localhost:3000)

The page will reload when you make changes.\
You may also see any lint errors in the console.
